## 依頼の書き方 (工程つき。モネが PR #25 に書く)
`[MONE-REQUEST] id=<ID> lane=work op=<操作> sha=<先頭の版>` に続けて、これまでの項目に加え、**`工程:` の一覧**を、番号つきで書く。1工程は、約1分で終わる大きさ。最後の工程が、結果 (`[AMU-RESULT]`) を書く。
