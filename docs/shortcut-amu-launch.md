# アム Chat 起動用ショートカットの指示文 (第10版・正本)

iPhone のショートカット「テキスト」アクションに入れる全文です。**このファイルが正本**です。直すときは、このファイルを直す PR を出し、アムの確認のあとで、ショートカットに写します。
第9版の変更: 対象を、台帳(amone-core の `collab/registry.json`)で自動起動が許されたプロジェクトの相談用 PR に限る形にした。アムが設計し(sandbox PR #23 の LAUNCH-9)、モネが確かめた。第8版の運用試験6項目は、台帳を読む部分を除き、そのまま引き継ぐ。
第10版の変更(アムの設計 KUNI83-SCOPE-3 を、モネが確かめて入れた): 台帳の `reviewTargets` に書かれた PR だけを、**読むだけ**でレビューしてよい形を足した。相談を受けて回答を書く場所は、今までどおり sandbox PR #23 だけ。台帳の変更は権限付与とみなさず、台帳が main に Merge されたものだけを見る。起動メールは、未回答の相談がある間は送らず、回答が届いてから次を1通で送る(モネ側の決まり)。

## コメントの書式 (モネとアム)
- 相談: `[MONE-ASK] id=<相談ID> lane=chat op=<操作> round=1 status=open`
- 追加の返事: `[MONE-REPLY] id=<相談ID> round=<2か3>`
- 回答: `[AMU-ANSWER] request=<相談ID> round=<同じround> source=<処理した元コメントの番号>`
- 取消: `[MONE-ASK] id=<相談ID> status=cancel`

## 起動
- 起動の合図は、メールです。モネが、アムの Gmail から、プッシュで届くアカウント宛てに、件名 `[AMONE-CHAT]` のメールを送ります(宛先のアドレスは、この文書には書かない)。
- ショートカットのオートメーションの条件: 差出人 = アムの Gmail、件名に `[AMONE-CHAT]` を含む(アカウントの指定はなし)。
- メールは合図だけで、承認の根拠にしない。
