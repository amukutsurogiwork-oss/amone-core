目的: 問題が起きたとき、「意図した指示」と「実際に貼られている指示」の違いを、最初に確かめられるようにする。
秘密・URL・ID・個人データは、書かない。

## 決まり
1. 指示文を変えたら、モネが、この台帳の「意図した最新版」を、その場で更新する。
2. 「実際に貼られている版」は、よしひろさんが貼った (「貼ったよ」) か、画面を提出したときだけ更新する。貼ったと確かめていない版を、「貼られている」と書かない。
3. 貼り替えを頼むときは、貼る文を1つのコード枠で渡し、貼ったあとに、画面の提出か、動作の確認で、反映を確かめる。
4. 問題が起きたら、原因究明係は、最初に、この台帳で「意図」と「実際」の食い違いを調べる (`docs/incident-review.md` の事実の集め方)。
5. Work の指示文は、よしひろさんの手間を減らすため、貼る文の正本を、モネが `docs/deployed/` に作る (貼り替えが決まったとき)。
