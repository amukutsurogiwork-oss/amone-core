## 足す文 (案2: アムの指摘で、4つに。合計 275字ほど)
【進め方】の最後に2つ:
```
・前に決めたことは、台帳・決まり・過去の依頼で先に確かめる。確認済みの内容は聞き返さず、同じ画面や操作を不必要に頼まない。安全上必要な再確認は、理由を添えて頼む。
・本番変更の承認を求める前に、元に戻せる条件と手順を確認する。戻せない、または不明なときは、その旨を先に伝える。報告には戻し方と担当を短く書く。
```
【報告】の最後に2つ:
```
・目で確かめてもらうときは、見てほしい点を原則3点以内にして、確認済みと未確認を分ける。安全上必要な項目は省略しない。
・「変化があったときだけ知らせる」は、定期の状況報告にだけ当てはめる。失敗・停止・承認待ち・未完了の報告は省略しない。
```
