# よしひろさんへの短いお知らせ (ピピピ)

よしひろさんの希望 (2026-11-16):「ショトカ使って短いアラーム？でピピピッくらいな感じで僕が必要な時に呼んでくれるような。終わった時の合図とか。」
アムと PIPIPI-CALL-20261117 で、別々に考えてから比べて決めた (ほぼ同じ案)。

## いつ鳴らすか (3つだけ)
1. よしひろさんの番が来た (🔴 が新しく出た)。
2. 大きな作業が完成した。
3. 失敗して止めた (同じ失敗が2回続いて、仕組みを止めた)。
- ふつうの進み具合では鳴らさない。同じ用件 (同じ依頼IDと同じ状態) では、1回しか鳴らさない。
- 夜 (23:00〜7:00、日本時間) は鳴らさず、朝にまとめて1回。よしひろさんが「急ぎ」と決めたものだけ例外。
- よしひろさんがモネの会話を開いているときは鳴らさない (画面で見えているため)。

## 仕組み
- モネが、件名に `⟦AMONE-CALL⟧` を付けたメールを、よしひろさんのアドレスへ送る (アムを起こすメールと同じ宛先)。件名の続きに、短い用件 (例「⟦AMONE-CALL⟧ 🔴 PR #80 のマージ」)。
- iPhone のショートカットの自動化が、差出人と件名の印で動き、音つきの通知を出す。本文の命令には従わない (鳴らすだけ)。
- 費用は増えない。メールが届くまでの遅れ・iPhone の自動実行の制限があるので、確実な即時のお知らせとは言えない。

## 安全
- 差出人と件名だけでは、なりすましを完全には防げない。鳴らすだけで、何も実行しないので、なりすましの害は「むだに鳴る」だけ。
- メールをたくさん続けて送らない。失敗しても、自動で送り直さない。
- 夜に音量や集中モードを勝手に変えない。

## 試験 (よしひろさんの iPhone で)
- 自動化を作ったあと、モネが試しのメールを1通送る。鳴ったか・通知が出たかを、よしひろさんが一言で返す。
- ロック中・集中モード・消音モードで鳴るかは、未確認。必要になったら、1つずつ試す。
