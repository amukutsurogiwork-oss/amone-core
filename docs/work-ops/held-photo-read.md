# Work の操作 `held-photo-read` (保留の写真を、画面で見て、数字を読み取る。読み取りだけ)

よしひろさんの承認の範囲 (2026-11-12、本人の直接の文): **保留の写真 (11/4、11/6、11/10 に送った分) の、画面の数字と確認用の値を、Work が読み取ること。読み取りだけ。変更・共有・削除・外部送信はしない。期限は 2026-11-19。**
この操作は、本番のデータを、**読むだけ**。書き込み・編集・並べ替え・コメント・共有の変更・ダウンロードの保存・削除は、一切しない。
秘密・URL・ID・写真のファイル名は、GitHub にもチャットにも書かない。書くのは、下の「報告」の項目だけ。

## 依頼の書き方 (モネが、sandbox の専用 PR に書く)
```
[MONE-REQUEST] id=<ID> lane=work op=held-photo-read sha=<この依頼を書く sandbox の PR の、いまの先頭の版>
対象: 国永の共通データベース (Drive の名前で特定)。「フォームの回答 1」シートの、行 <行番号の一覧> (読み取りのみ)
読み取る写真: <行番号ごとの、写真の枚数と、順番 (左から何枚目か)。ID・リンクは書かない>
期限: <日付>
承認の範囲: 上の行の写真を、画面で開いて、見える数字を読み取り、結果を報告する。変更・共有・削除・保存・外部送信は含まない。
承認の記録: よしひろさん本人が、Work のチャットに直接、この範囲 (読み取りだけ、期限つき) を送る。原文と依頼の内容の一致は、Work が確かめる。
報告: どんな状態で終わっても、[AMU-RESULT] request=<ID> を1回、GitHub に書く。
取消: [MONE-REQUEST] id=<ID> status=cancel があれば、何もせず止まる
次の担当: アム Work
```

## 手順 (Work)
0. **実行前の確認** (許可の方針 第9版、`docs/approval-policy.md`): 台帳 (collab/registry.json) と、この手順書の最新を取り直す。依頼の全項目、取消の有無、依頼を書いた PR の先頭の版が `sha=` と同じこと、既存の結果が無いことを確かめる。依頼の「承認の記録」に、よしひろさんがモネの会話で出した許可の原文と日付が引用されていて、この操作の範囲と一致すること(Work のチャットでの再送は要らない)。なければ、読み取りだけの範囲は進めてよいが、範囲外は止まる。お金がかかることは、常に止まる。
1. Drive で、依頼の名前の共通データベースを開く (名前で特定。同名が複数なら、推測せず止まる)。**開くだけ。**シートの編集、並べ替え、フィルタ、コメント、共有の変更はしない。
2. 「フォームの回答 1」シートで、依頼の行の、写真の列を見る。写真のリンクを、1つずつ開く。リンクや ID は、書き写さない。
3. 写真を、画面で見て、読み取る (下の「報告」)。写真の保存・ダウンロード・共有・名前の変更・移動・削除は、しない。ログインや確認が出たら、迂回せず止まる。
4. 読み取った値は、**見えた数字だけ**を書く。読めない・自信がない所は、「読めない」と書く。推測で埋めない。
5. 本番のシートには、何も書かない。終わったら、開いたものを閉じる。

## 報告 (`[AMU-RESULT] request=<ID>`)
写真ごとに、1ブロック (行番号、その行の何枚目か、を必ず付ける)。
- 種類: 配信終了画面 (配信時間・歌った曲数が出る) か、プロフィール画面 (フォロワー・メンバーシップが出る) か、そのほか。
- 画面の中の日付・時計 (見える場合)。Drive の詳細パネルに、撮影日時・更新日時が出る場合は、それも。
- 見える数字 (名前と値のペア): リーグ、歌推し人数、枠内月間推しPt、推しボーナスの倍率、フォロワー、残高、スーパーいいね、コメント数、配信時間、歌った曲数、など。画面に書いてある文字のとおりに (K や M の単位、+ や 括弧の差分も、そのまま)。
- 読めなかった項目の一覧と、理由 (ぼやけ・欠け・隠れ)。
- 最後に: 見た写真の枚数、読み取れた枚数、止まった理由 (あれば)。
- **書かないもの**: 写真のファイル名・リンク・ID、コメントの本文、名前、配信のタイトル。

## 動かないこと・Work がしないこと
- 数字の判定 (どの日に入れるか、反映してよいか) は、モネ。Work は、見えたとおりに報告するだけ。
- 本番のデータの変更、共有、削除、外部送信、課金はしない。
- 画面で機密 (パスワード・ID・メールアドレス) が見えても、転記しない。
- パスワードや認証コードが要る所では止まる。
