# AMONE 止まりの記録 (原因を直して、同じことで止まらないようにする)

止まった・失敗した・取りこぼした、ことがあったら、**必ずここに1行足し、直しまで進める**。直しは、先に再現するテストか確認を用意してから行う(テストのためのテストは作らない)。
秘密・鍵・非公開のID/URL・個人データ・写真の識別番号や数値は、ここに書かない。

## 決まり
1. 気づいたのはだれでも(モネ・アム・Codex・よしひろさん)、モネが、その日のうちにこの表へ1行足す。アムが `status=blocked` を出したときも同じ。
2. 1行は「日付・どこで止まったか・原因・直し・状態」。原因が分からないときは「不明」と書き、確かめ方を書く。
3. 直しは、手引き・指示文・コード・モネの手順のどれかに入れる。会話の中だけの約束にしない。
4. 同じ原因で2回止まったら、直し方が足りないということ。その直しをやり直し、よしひろさんに一言知らせる。
5. 状態は「直し済み(確認つき)」「直し中」「不明」「よしひろさんの判断待ち」のどれか。確かめていないものを「直し済み」と書かない。
6. 月に一度、または大きな変更のあとに、「直し中」「不明」が残っていないかを見直す。
